# 💵 تطبيق money dl (Android APK)

هذا المشروع جاهز لبناء ملف تثبيت أندرويد (**APK**) تلقائياً عبر **GitHub Actions** مع أيقونة النقود المخصصة واسم التطبيق **money dl**.

## خطوات الرفع وبناء التطبيق:
1. فك الضغط عن حزمة `money-dl-github-apk.zip` وتأكد من ظهور مجلد `.github` المخفي بجانب `assets` و`www` و`package.json` و`capacitor.config.json`.
2. ارفع جميع الملفات والمجلدات المستخرجة إلى مستودعك في **GitHub**.
3. افتح تبويب **Actions** في المستودع، وبعد انتهاء مهمة **Build Android APK** انزل إلى قسم **Artifacts** لتحميل ملف `money-dl-apk` وتثبيت `money-dl.apk` على هاتفك.
